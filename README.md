# OSHA Safety Dashboard

A workplace safety analytics dashboard designed to monitor OSHA metrics, incident trends, inspections, corrective actions, and key safety performance indicators.

## Features

- OSHA KPI Tracking
- TRIR Calculations
- DART Rate Monitoring
- Near Miss Analysis
- Safety Observation Tracking
- Corrective Action Management
- Monthly Safety Performance Dashboard
- Inspection Compliance Tracking

## Technologies Used

- Python
- SQL
- Power BI
- Excel
- GitHub

## Dashboard Metrics

### OSHA Metrics
- Total Recordable Incident Rate (TRIR)
- Days Away Restricted Transfer Rate (DART)
- Lost Time Incident Rate (LTIR)

### Safety Metrics
- Near Miss Reports
- Safety Observations
- Open Corrective Actions
- Closed Corrective Actions
- Training Completion Rate
- Inspection Completion Rate

## Project Overview

This project demonstrates data analytics and workplace safety management concepts through the development of a safety performance dashboard. The dashboard provides management teams with visibility into safety trends, incident rates, and compliance performance.
